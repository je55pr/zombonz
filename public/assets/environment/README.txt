Zombonz environment runtime textures

- arm.jpg: packed linear data, R=AO, G=roughness, B=metallic

Decals:
- basecolor.webp: sRGB
- normal.webp: OpenGL normal map, linear
- opacity.jpg: grayscale alpha/opacity, linear
- roughness.jpg / ao.jpg where present: linear data
